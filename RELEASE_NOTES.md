# TNS Energy Studio 0.2.0

Первый релиз миграции на Rust + React + Tauri 2.

## Что внутри

- Полный паритет расчёта и выходной книги Excel: значения, формулы, merge,
  freeze, стили Segoe UI, number formats, условное форматирование и гиперссылки.
  Полная `xlsx_signature` на golden-фикстурах — **0 расхождений**.
- `detect_statement`, `process_statement`, `cancel_statement`, история, бэкап,
  открытие файла/папки — реальные Tauri-команды без моков.
- Прогресс `process-progress`, отмена, результаты и баланс в UI.
- Локальная SQLite: история расчётов, дома, тарифы, локальные бэкапы.
- Обновления только через GitHub Releases + `latest.json` + Tauri updater.
- S3, Yandex и облачная синхронизация отсутствуют.
- Проверки: 32 Rust-теста, 22 pytest passed / 0 xfailed, UI typecheck/build.
- Живой smoke: расчёт из UI создал xlsx, полностью совпадающий с golden.

## Установка

Скачайте NSIS-установщик `TNS.Energy.Studio_0.2.0_x64-setup.exe` из GitHub
Release и запустите его. Обновления — через встроенный updater.

## Ограничения

- Нативный диалог выбора файла/папки проверен вручную не до конца: диалог
  открывается, автоматический выбор файла в e2e не выполнялся.
- Входная ведомость должна быть одно-листовой; multi-sheet active sheet пока
  не поддержан.
- Подпись updater требует приватного ключа Tauri; Authenticode — сертификата
  Windows. Оба настраиваются через secrets репозитория, а не коммитятся.
- Текущий релиз опубликован как `v0.2.0-1`; будущие релизы запускаются обычным тегом `v*` после настройки секретов.
