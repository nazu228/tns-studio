# TNS Energy Studio 0.2.1

Релиз PDF-поддержки: ведомости ТНС теперь можно считать прямо из PDF.

## Что нового

- Приложение принимает **PDF** как файл и как папку — вместе с `.xlsx`.
  Диалоги выбора видят оба формата; в папке PDF считаются отдельными входами.
- Встроенный парсер PDF (PDFium + векторная сетка) находит только ведомости ТНС:
  город, дом и корректировки. Ненужные страницы (счета, УПД, акты, титулы)
  пропускаются и не конвертируются.
- Несколько ведомостей в одном PDF автоматически разделяются: каждая пишется
  в свой стандартный xlsx через golden-верифицированный writer
  (`Сводка по домам` + `Ведомость ЭП`, формулы, стили, CF, гиперссылки).
- Имена файлов по договору: `<Договор>_<Месяц>_<Год>.xlsx`; корректировки —
  `<Договор>_<Месяц>_<Год>_за_<БазовыйМесяц>_<БазовыйГод>.xlsx`; дубликаты
  внутри одного прогона получают `_2`, `_3`.
- Прогресс и отмена работают и для PDF; каждая ведомость пишется в локальную
  историю SQLite как обычный расчёт.
- `pdfium.dll` входит в установщик как ресурс приложения.

## Проверено

- 62 Rust-теста (tns-core 16, tns-db 4, tns-excel 7, tns-pdf 26, tauri 9),
  22 pytest passed / 0 xfailed, UI typecheck/build, guard по `legacy/pyqt`
  и golden — чистый.
- Живой smoke: dom PDF → `23110603789_Октябрь_2026.xlsx` (3 дома, 137107.602);
  226-страничный PDF → две ведомости в одном прогоне (736051.312 и
  корректировка 1032745.77). Выходные книги совпадают со стандартом.

## Установка

Скачайте NSIS-установщик `TNS.Energy.Studio_0.2.1_x64-setup.exe` из GitHub
Release и запустите его. Пользователи 0.2.0 получат обновление через встроенный
updater (`latest.json`).

## Ограничения

- PDF-парсер рассчитан на текстовые ведомости ТНС с векторной сеткой;
  отсканированные PDF без текста отклоняются.
- Нативный диалог выбора файла/папки автоматизирован не полностью; диалог
  открывается, выбор проверялся вручную.
- Входная xlsx-ведомость должна быть одно-листовой; multi-sheet active sheet
  пока не поддержан.
- Authenticode — опционально через секреты; updater подписывается ключом Tauri.
