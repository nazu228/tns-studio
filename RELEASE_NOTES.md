# TNS Energy Studio 0.2.2

Обновление UX и надёжности PDF-обработки.

## Что нового

- **Большое уведомление об ошибках**: если ведомость не обработалась,
  показывается крупное красное поле с описанием ошибки — а не мелкая строка.
- **PDF с несколькими ведомостями**: битые блоки пропускаются с предупреждением,
  остальные считаются нормально. Раньше одна сломанная ведомость убивала весь PDF.
- **Excel-файлы называются по договору** — как PDF:
  `23110604327_Октябрь_2026.xlsx` вместо `Город_Октябрь_2026.xlsx`.
- **Папка создаётся автоматически** из месяца ведомости — без ручного выбора.
- **Выбор месяца/года убран** из UI: приложение читает месяц и год из самой
  ведомости, а не из выпадающих списков.
- **Частичные выгрузки 1С**: PDF, вырезанный из большого документа
  (стр. 1–998 из 1535), обрабатывается корректно; нумерация страниц
  распознаётся по фактическому блоку, а не по исходному документу.
- **Пустые `main`/`sub_deduct`** в корректировках не вызывают ошибку —
  обрабатываются как 0.

## Исправлено

- `pdfium.dll` теперь загружается из установленной папки приложения
  (раньше NSIS ложил DLL в подпапку `_up_/crates/tns-pdf/vendor/`,
  и release-версия падала при обработке PDF).
- Расхождение `main ≠ delta×k` в корректировках — предупреждение, а не ошибка
  (там бывают ручные переопределения и минимальные начисления).

## Установка

Скачайте `TNS.Energy.Studio_0.2.2_x64-setup.exe` из GitHub Release и запустите
поверх предыдущей версии. Все данные (SQLite история, дома, тарифы) сохраняются.
